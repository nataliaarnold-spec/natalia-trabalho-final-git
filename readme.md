# Farma Hora

Nome: Natalia Arnold  
Data: 23/09/2026

## Sobre

O Farma Hora é um site criado para ajudar na organização dos horários dos medicamentos. A proposta é facilitar o acompanhamento dos remédios e lembrar o usuário dos horários durante o dia.

## Funcionalidades

- Cadastro de medicamentos
- Definição dos horários dos medicamentos
- Aviso do próximo medicamento
- Marcar medicamento como tomado
- Alertas para os horários
- Salvamento das informações no navegador

## Tecnologias

- HTML
- CSS
- JavaScript
- LocalStorage

## Arquivos

- `index.html` - página principal
- `style.css` - estilos do site
- `script.js` - funções e interações do site
- `readme.md` - documentação do projeto
- `.gitignore` - arquivos que não devem ser enviados ao Git

## Como usar

1. Abra a pasta do projeto.
2. Abra o arquivo `index.html` no navegador.
3. Cadastre os medicamentos e seus respectivos horários.

Não é necessário instalar programas ou dependências para executar o projeto.
