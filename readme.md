# Farma Hora

Nome: Natalia Arnold  
Data: 23/09/2026

## Sobre

O Farma Hora é um site para ajudar a organizar os horários dos medicamentos.

## Funcionalidades

- Cadastro de medicamentos
- Horários dos medicamentos
- Aviso do próximo medicamento
- Marcar medicamento como tomado
- Alertas

## Tecnologias

HTML, CSS e JavaScript.

## Arquivos

- index.html - página principal
- style.css - estilos do site
- script.js - funções do site

## Como usar

Abrir o arquivo index.html no navegador.
